# File Handling Assignment

## Description
This Python program demonstrates file handling and exception handling.  
It:
- Creates `notes.txt` with sample text.
- Reads the file and adds line numbers to each line.
- Writes the modified content to `modified_notes.txt`.
- Allows the user to open a file with error handling.

## Files
- `FileHandlingAssignment.py` – Main script  
- `notes.txt` – Sample input file  
- `modified_notes.txt` – Output file generated by the script  

## How to Run
```bash
python3 FileHandlingAssignment.py
